# WHENDESK

WHENCOMMAND를 기본 화면으로 사용하는 Windows 데스크톱 앱입니다.

Command는 아이콘 바로 옆에 입력하는 한 줄 화면입니다. 연결된 미디어가 있을 때만 입력 오른쪽에 이전 곡·재생/일시정지·다음 곡 버튼을 표시합니다. 입력에서 Shift+Tab으로 미디어 버튼에 접근할 수 있습니다. 별도의 상단 창 조작 바는 표시하지 않으며, Command 입력줄의 여백·아이콘 또는 대시보드 사이드바·화면 제목의 빈 영역으로 창을 옮길 수 있습니다.

기존 WHENCOMMAND의 입력부와 같은 폭 560px·높이 54px를 사용합니다. 검색 결과 행은 40px이고 창은 최대 390px까지 자라며, 나머지 결과는 방향키로 선택해 스크롤합니다. 앱 전체의 입력·버튼·목록·탭·날짜에는 포커스 외곽선과 그림자를 그리지 않습니다. Work의 선택 탭은 기존 밑줄로 표시하고, 포커스·호버 때도 탭 배경을 칠하지 않습니다. Windows 프레임 테두리도 제거했습니다.

상위 메뉴는 **Dashboard · Work · Note · Calendar**입니다. **InBox · ToDo · Waiting · Done · Projects**는 Work 화면 안쪽의 가로 탭입니다. 목록에서 **Tab / Shift+Tab**으로 분류를 순환하고, 편집 중에는 입력 필드를 이동합니다. 탭에서 좌우 방향키·Home/End로 분류를 고르고 아래 방향키로 목록에 진입할 수도 있습니다. Settings는 사이드바 아래에서 엽니다. Command에서도 영문 메뉴 이름과 기존 한국어 이름으로 같은 화면을 찾을 수 있습니다.

- 검색 입력 중 **Tab**: 대시보드 펼치기
- 대시보드에서 **Esc**: Command로 돌아가기. 열린 대화상자가 있으면 먼저 닫습니다.
- **Ctrl+K**: Command 열기. 입력 필드의 일반 Tab 이동은 유지합니다.
- **Ctrl+/**: 단축키 안내 열기·닫기. Esc로도 닫을 수 있고, 입력 내용과 커서를 유지합니다.
- Command에서 **Alt+Enter**: 선택한 결과의 동작 목록. ↑·↓와 Enter로 실행하고 Esc로 검색 결과로 돌아갑니다.
- **Ctrl+Enter**: 보조 동작. 앱·파일은 위치 열기, 스크립트는 파일 열기입니다.
- Command에서 **↑·↓**로 결과를 선택하고 **Enter**로 실행합니다. **Ctrl+K**를 다시 누르면 검색어 전체를 선택합니다.
- 기본 전역 단축키: **Alt+Space**. 빠른 할 일 수집: **Ctrl+Alt+Space**.

기존 Work·Note·Calendar·WHENCOMMAND를 연결합니다. 메모는 WHENNOTE의 첫 줄 제목·본문 자동 저장·초성/태그 검색·고정·보관함·휴지통·링크와 백링크·Markdown 미리보기·이미지 첨부·내보내기를 재사용합니다. 할 일·인박스·대기·완료, 프로젝트, 마감, 반복 일정, ICS와 구독, 앱·파일 검색, 계산·단위 변환, 기존 스크립트와 시스템 명령도 사용할 수 있습니다. Music은 연결된 Windows 미디어 컨트롤을 사용합니다. Mail·Terminal은 포함하지 않습니다.

## 키보드로 사용

| 범위 | 조작 |
| --- | --- |
| 화면 이동 | Alt+H Dashboard, Alt+T Work/ToDo, Alt+I Work/InBox, Alt+W Work/Waiting, Alt+D Work/Done, Alt+N Note, Alt+C Calendar, Alt+S Settings |
| 새 항목·저장 | Ctrl+N 현재 화면에서 작성, Ctrl+S 저장. 할 일 캡처는 Enter 저장 후 InBox의 새 행으로 이동하여 M·D 등으로 바로 분류. 입력에서 ↓·Esc로 목록 복귀 |
| Work 분류 | 목록에서 Tab·Shift+Tab 순환하며 해당 분류의 마지막 행으로 복귀. 빈 탭을 거쳐도 다음 목록으로 바로 진입. 탭에서 ←→·Home/End 분류 선택, ↓ 목록 진입 |
| 할 일 목록 | ↑↓·J/K·Home/End·PageUp/Down 선택, Enter 편집, Space 완료·해제, E 제목, D 마감, N 상세, M 프로젝트, W 대기 상대 지정, P·R 재촉 기록, Delete·X 삭제, U·Ctrl+Z 연속 되돌리기 |
| 할 일 편집 | Tab·Shift+Tab으로 필드 이동, Ctrl+Enter 또는 Esc로 목록 복귀 |
| Work 검색 | /·Ctrl+F 검색, Enter·↓ 목록 복귀, Tab으로 프로젝트 필터·정렬 이동, Esc 검색 해제. 목록에서 Tab은 검색을 유지하며 분류 순환. F는 ToDo 마감 필터, H는 완료 기록 |
| 프로젝트 | Projects에서 Ctrl+N·N 추가, E 이름 수정, Shift+↑↓ 순서, Delete·X 보관, U 보관함 전환, 보관함 Enter 복원. 할 일에서는 M으로 지정하며 InBox 항목은 ToDo로 이동 |
| 메모 | Ctrl+N 새 메모, Ctrl+F 검색, Ctrl+S 저장, Ctrl+E 미리보기, Ctrl+P 고정, Ctrl+Shift+A 보관·해제 |
| 메모 목록 | ↑↓ 선택, Enter 편집, Ctrl+Shift+M/B/T로 메모·보관함·휴지통, Delete 삭제, Ctrl+Shift+Z 복원 |
| 메모 파일 | Ctrl+Shift+I 이미지 선택, Ctrl+Shift+E Markdown 내보내기. 이미지 붙여넣기도 지원 |
| 캘린더 | 날짜 ←→ 하루·↑↓ 일주일, PageUp/Down 월 이동, T 오늘, Ctrl+N 새 일정, Enter 날짜의 일정 목록·일정 편집 |
| 대화상자 | Tab·Shift+Tab은 내부 순환, Ctrl+S 저장, Esc 닫기. 일정 목록의 Delete는 삭제 확인 화면으로 이동 |
| 돌아가기 | Esc는 편집·대화상자·동작 목록부터 닫고 Command로 복귀. Ctrl+K는 Command로 이동하며 일정 대화상자 초안은 닫지 않음 |

단축키 안내는 화면에 상시 표시하지 않고 Ctrl+/에서 확인합니다. 입력 중에는 목록용 문자 단축키가 본문을 가로채지 않습니다.

Work는 원본 WHENWORK의 저장소와 날짜·검색·그룹 계산 코드를 재사용합니다. 마감일은 `오늘`, `내일`, `모레`, `+3`, `3일`, `8-12`, `2026-08-12`로 지정하고 빈 값으로 해제합니다. ToDo는 프로젝트 순서대로 묶이며 마감 배지는 D-/D+로 표시합니다. Waiting은 상대·경과일·재촉 횟수를 보여주고, 30분 내 재촉은 횟수를 중복 증가시키지 않습니다. Done은 7일·30일·전체 기록을 날짜별로 보여줍니다.

Work 검색은 초성·제목·본문·프로젝트·대기 상대를 지원합니다. `마감순`, `최신순`, `오래된순`, `이름순`, `마감있음`, `마감없음`, `마감지남`, `오늘까지`, `이번주`, `메모있음`, `미완료`, `#프로젝트`, `#미지정`을 조합할 수 있습니다. 지난 완료·삭제 항목은 검색 결과 아래에 표시되며 Enter·Space로 되살릴 수 있습니다. 보관한 프로젝트는 완료 기록을 유지하고 미완료 항목을 InBox로 옮깁니다. 같은 실행에서 보관을 되돌리면 아직 재분류하지 않은 항목도 복귀합니다.

## 실행

빌드 결과의 `WHENDESK.exe`를 실행합니다. `resources`와 DLL·로캘 폴더를 포함한 **폴더 전체**를 함께 보관해야 합니다. 서명되지 않은 Windows 폴더형 배포입니다.

개발 실행은 이 프로젝트의 `run.cmd` 또는 다음 명령을 사용합니다.

```powershell
npm install
npm start
npm test
npm run build
```

현재 PC의 기존 Electron 런타임도 개발 실행과 빌드에 재사용할 수 있습니다. 직접 지정하려면 `WHENDESK_ELECTRON`(실행 파일), `WHENDESK_ELECTRON_DIST`(런타임 폴더)를 사용합니다. Node.js 24 이상이 필요합니다. 빌드는 별도 네트워크 다운로드 없이 이미 설치된 Electron 런타임을 패키징합니다.

Command에서 Esc를 누르거나 시스템에서 창을 닫으면 트레이로 숨깁니다. Alt+S로 여는 설정의 **앱 종료** 또는 트레이의 **종료**로 완전히 종료합니다. 종료 전에 편집 내용을 저장합니다. 기존 WHENCOMMAND가 Alt+Space를 사용 중이면 설정에서 WHENDESK 단축키를 변경하세요.

단축키 설정 필드에 원하는 키 조합을 누르면 기록됩니다. Delete/Backspace는 해제, Esc는 저장된 값으로 복귀하며, 조합 문자열을 붙여넣을 수도 있습니다. 중복·잘못된 조합·앱 내부 예약키를 확인하고, 등록이나 저장에 실패하면 이전 단축키를 유지합니다. 일정·프로젝트 대화상자 안에서는 Ctrl+K로 초안을 닫지 않고 Tab도 대화상자 내부에서 이동합니다.

## 저장과 기존 데이터

개발 실행은 프로젝트의 `.local/`, 배포본은 `%APPDATA%\whendesk`를 사용합니다. `--data-dir=<절대 경로>`로 별도 저장 폴더를 지정할 수 있습니다. 기존 개별 앱의 저장소와 단일 인스턴스 락을 공유하지 않습니다.

설정 → **기존 데이터 복사해 가져오기**에서 `whenwork`, `whennote`, `whencalendar`, `whencommand` 폴더가 있는 상위 폴더(보통 `%APPDATA%`)를 선택합니다. 원본 데이터베이스는 읽기 전용으로 열고 SQLite 백업 API로 일관된 복사본을 만듭니다. 캡처 큐도 복사본에서만 재생하며 메모 이미지를 함께 복사합니다. 가져오기 직전에 현재 WHENDESK 데이터는 `backups/`에 보존합니다.

**백업 내보내기/복원**은 Work·Note·Calendar·Command 데이터베이스, 메모 첨부와 설정을 포함합니다. 복원 전에 체크섬과 스키마를 확인하며, 실패하면 이전 파일을 되살립니다. 메모가 없는 구형 백업을 복원하면 현재 메모는 보존합니다. ICS는 캘린더 일정용, Markdown은 메모와 첨부용이며 전체 앱 백업은 JSON을 사용합니다. 원본 개별 앱으로 역동기화하지 않습니다.

스킨과 라이트/다크 설정은 설정 → 모양에서 별개로 선택합니다. 외관 변경과 Command/대시보드 전환은 작성 내용·검색어를 유지합니다. 단축키 안내는 Ctrl+/ 또는 설정에서 열 수 있습니다.

## 검증

- `npm test`: 저장·재시작·큐·반복 일정·구독·ICS·백업·복원·검색 엔진 테스트와 키맵(`renderer/keymap.js`) 충돌·미사용 항목 검사
- `node tools/e2e-desktop.cjs`: 실제 Electron의 Tab/Esc·데이터 저장·캘린더·외관·클립보드·재시작 테스트
- `node tools/e2e-minimal.cjs`: Ctrl+/ 도움말·초안·커서·대시보드 크기·스킨/모드 보존 검사
- `node tools/e2e-command.cjs`: 실제 개발 렌더러·검색 엔진으로 보조 동작·검색 경합·IME·단축키 설정 검사. OS 실행과 미디어·클립보드 효과는 기록만 합니다.
- `node tools/e2e-keyboard-notes.cjs`: 마우스 입력 없이 메모·할 일·캘린더·설정과 파일 기능을 개발본에서 검증
- `node tools/e2e-work.cjs`: Work 내부 탭·프로젝트 지정/관리·자연어 마감·대기·재촉/연속 되돌림·원본 검색 규칙을 키보드로 검사
- `node tools/e2e-focus-flow.cjs`: 6개 스킨/모드 조합의 전 화면 포커스 228개 검사와 캡처·탭 왕복·검색/필터·캘린더 진입·저장 지연 중 포커스 흐름 검사
- `node tools/e2e-command-bar.cjs`: 한 줄 Command·조건부 미디어·입력 및 버튼 포커스·작은 창 배치를 모의 미디어로 검사
- `npm run smoke -- --headless --data-dir=<테스트 폴더>`: 별도 저장소 부팅 검사

GUI 테스트는 Windows의 일반 사용자 세션에서 실행해야 합니다. 제한된 앱 컨테이너에서는 Electron 자체가 시작되지 않을 수 있습니다. 자동 테스트는 실제 다른 앱·사용자 스크립트·시스템 명령·미디어 재생을 실행하지 않습니다. 파일 검색은 Windows Search 서비스와 OS 인덱스에 의존하며 사용 불가 시 실제 상태를 표시합니다.

현재 배포에는 별도 자동 업데이트 서버나 서명된 설치 관리자를 설정하지 않았습니다.
